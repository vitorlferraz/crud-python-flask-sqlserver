# 🚀 CRUD de Clientes - Flask + SQL Server

Sistema completo de cadastro de clientes com frontend e backend.

## 📌 Funcionalidades

- Criar clientes
- Listar clientes
- Atualizar clientes
- Deletar clientes

## 🛠 Tecnologias

- Python (Flask)
- SQL Server
- HTML, CSS, JavaScript

## ▶️ Como rodar

1. Instalar dependências:
pip install flask pyodbc

2. Rodar:
python app.py

3. Abrir:
http://localhost:5000
